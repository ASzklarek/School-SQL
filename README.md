# School-SQL
Relacyjna baza danych SQL zaprojektowana dla systemu zarządzania szkołą. Projekt obejmuje tabele uczniów, nauczycieli, opiekunów, klas, przedmiotów i ocen wraz z kluczami głównymi i obcymi oraz ograniczeniami CHECK i UNIQUE. Repozytorium stanowi bazę pod dalszy rozwój: agregacje, zagnieżdżone zapytania, procedury, triggery i transakcje.
